# OATEC PlayerTv

مشغّل IPTV أصلي لـ Android، مع أولوية لواجهة التلفاز والريموت. التطبيق لا يستخدم WebView ولا يتضمن شراءً أو اشتراكًا أو تفعيلًا مدفوعًا.

## المتطلبات

- JDK 17 أو أحدث.
- Android SDK Platform 36 وAndroid Build Tools متوافقة مع Android Gradle Plugin 9.0.
- Gradle 9.1 أو أحدث.
- جهاز Android TV أو هاتف Android للتثبيت والتحقق من التشغيل.

## البناء

```sh
gradle :app:assembleDebug
gradle :app:testDebugUnitTest
```

ينتج البناء APK منفصلاً لكل معمارية داخل `app/build/outputs/apk/debug/` (مثل `app-arm64-v8a-debug.apk` و`app-armeabi-v7a-debug.apk`) لتجنب تنزيل مكتبات MPV الأصلية الخاصة بكل المعماريات معاً. ثبّت الملف المطابق لمعمارية جهازك. يتطلب Gradle إعداد Android SDK عبر `ANDROID_HOME` أو `local.properties`؛ لا ترفع `local.properties` إلى Git.

## الميزات الحالية

- واجهة Android أصلية بـ Kotlin وJetpack Compose وMedia3، مع نقطة تشغيل Android TV وواجهة D-pad.
- تنقل جانبي قابل للتمرير، وتخطيط مضغوط للشاشات الصغيرة في landscape؛ وصفوف الملصقات قابلة للتمرير أفقيًا.
- إضافة عدة مصادر Xtream-compatible وروابط M3U، واستيراد ملف M3U إلى مساحة التطبيق الخاصة.
- استيراد غير متزامن مع حد 40 MB، وفحص HTTP/HTTPS والتحويلات ومهلات الاتصال.
- تخزين إعدادات المصدر مشفرة بـ AES-GCM مع مفتاح Android Keystore.
- تصفح قنوات Live وقنوات Xtream للأفلام والمسلسلات والحلقات، مع بحث وفئات ومفضلة.
- تحميل بيانات Xtream عند فتح القسم المطلوب فقط، وقراءة JSON تدريجيًا مع إيقاف القراءة بعد حد العناصر لتفادي استهلاك الذاكرة دفعة واحدة.
- فئات قنوات مخصصة، نقل قناة بين الفئات، إخفاء واستعادة، وأرقام قنوات تحفظ محليًا عبر تحديث المصدر.
- تشغيل Media3 افتراضيًا مع محاولة بديلة لاختيار decoder عند تعذّر فتحه؛ يتحول التطبيق إلى MPV عند فشل Media3. يستخدم MPV فك الترميز بالهاردوير عند ملاءمته، مع تفعيل الرجوع التلقائي إلى فك الترميز البرمجي عند فشل أو عدم دعم decoder، ويتيح اختيار مسار الصوت والتحكم بالتقديم والإيقاف المؤقت. دعم الترميزات يبقى حسب بناء MPV والجهاز والمصدر، لذلك لا يمكن ضمان كل صيغة على كل جهاز.
- تشغيل ملء الشاشة مع ملء إطار الفيديو لتجنب الأشرطة الجانبية (وقد تُقصّ حواف بسيطة عند اختلاف نسبة أبعاد البث عن الشاشة)، تبديل القنوات من الريموت وإدخال رقم مباشر.
- عند اختيار فيلم أو مسلسل تظهر صفحة تفاصيل داكنة تعرض الملخص والبيانات المتوفرة؛ تفاصيل المسلسل لا تظهر عند فتح قائمة المسلسلات، بل بعد اختيار مسلسل.
- حفظ واستعادة موضع VOD والحلقات وعرض متابعة المشاهدة.
- تبويب Settings يتضمن تعطيل الاستئناف ومسح سجل المشاهدة، وزر Exit.
- قسم About يجلب عنوان ووصف الموقع الرسمي `oatec.store` عبر HTTPS، مع فتح الموقع في المتصفح بدل تضمينه داخل WebView.
- واجهة بألوان OATEC الرسمية من `oatec.store`: خلفية داكنة وذهبي وذهبي فاتح ونص أبيض/رمادي، مع مخطط Material داكن لمنع ظهور أسطح بيضاء افتراضية.

## قيود النسخة الحالية

- M3U يعرض عناصره كقنوات Live؛ تصنيف VOD والحلقات متاح حاليًا عبر Xtream فقط.
- لا يوجد EPG أو catch-up أو تسجيل أو تعدد شاشات أو مزامنة سحابية.
- ترتيب القنوات يدويًا وإدارة تاريخ المشاهدة غير مكتملين.
- حدود استيراد Xtream الحالية 20,000 قناة و20,000 فيلم أو مسلسل؛ حجم استجابة البث الأقصى 256 MB، وتظهر رسالة خطأ إذا تجاوز المصدر الحد بدل عرض قائمة ناقصة بصمت. مكتبات MPV الأصلية كبيرة، لذلك يُنتج البناء APK منفصلاً لكل ABI لتقليل حجم تنزيل كل جهاز.
- قبل نشر التطبيق أو إعادة توزيعه، راجع تراخيص وإشعارات MPV وFFmpeg وأي مكتبات native المضمنة؛ الالتزامات الدقيقة تعتمد على نسخ المكتبات وإعدادات بنائها.
- Fire TV غير مختبر فعليًا، ولا يُعلن دعم iOS أو Tizen أو webOS.
- توافق الترميزات والبث يعتمد على الجهاز ومزود الخدمة. اختبر صيغ البث على أجهزة الهدف قبل وصفها بالدعم.
- قد تحتوي روابط M3U أو Xtream على بيانات دخول. تُحفظ بيانات المصدر محليًا مشفرة، لكن حركة HTTP غير مشفرة؛ استخدم HTTPS إن كان مزودك يتيحه، ولا تشارك ملفات القوائم أو السجلات التي قد تتضمن بيانات اعتماد.
- لا يتحقق التطبيق من ملكية القنوات أو الحقوق. أضف فقط مصادر ومحتوى لديك تصريح باستخدامهما.

## الاختبارات

توجد اختبارات وحدات لمحلل M3U وحدّ عدد القنوات. شغّل أوامر Gradle أعلاه بعد تثبيت Android SDK. يحتوي الفرع على GitHub Actions لبناء APK وتشغيل اختبارات الوحدة عند كل دفع إلى فرع التطوير؛ راجع تبويب Actions للتأكد من نجاح آخر تشغيل وتنزيل ملفات APK الناتجة. لم يتوفر جهاز أو محاكي متصل لاختبار التشغيل الفعلي.
